# Relatório de validação

Salvar como `docs/migrations/<migration-slug>/evidence/validation-report.md`:

```markdown
# Validation Report — <migration>

Modo: COLLECT | REVIEW
Resultado: VALIDADA | VALIDADA COM RESSALVAS | NÃO VALIDADA

## Escopo validado
## Relação com migration-plan e roadmap
## Validação funcional
## Smoke tests
## Testes automatizados
## Build / qualidade
## Persistência, integração e segurança
## Avaliação comparativa
## Evidências e limitações
## Desvios, riscos e pendências
## Decisão de continuidade
## Conclusão
```

## Formato Jira-ready

Quando o usuário pedir um texto para o card, use:

```markdown
## Validação da migração
### Escopo validado
### Validação funcional
### Smoke tests
### Testes automatizados
### Build / qualidade
### Avaliação comparativa
### Evidências
### Pendências ou ressalvas
### Resultado
```

Inclua links/caminhos dos artefatos, status por item e o limite da conclusão.
Não atualize o Jira automaticamente.
